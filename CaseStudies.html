Coal LSL CLOUD STRATEGY · MIGRATE

SQL Server to AWS PostgreSQL — 100% of objects in three months.

Business problem

  • An AWS migration at risk of slipping
  • No in-house skills for mature SQL Server to PostgreSQL conversion
  • A need to prove nothing changed in translation

Solution — what we built

  • Full object conversion: every table, view, stored procedure and function
  • Rigorous validation of each object and dataset against source
  • Detailed, audit-ready reconciliation reporting at every step

Outcome

100%

Database objects migrated, validated and deployed. Delivered in exactly three months; the AWS migration kicked off on time.

MetLife DATA ADVISORY · GOVERN

Automated data quality and load audit — 99.9% integrity.

Business problem

  • Growing data volumes across a global insurer
  • No way to answer: can we trust this data, and did every record make it?
  • No organisation-wide view of where sensitive PII sits

Solution — what we built

  • A scalable data-quality framework built entirely in SQL, so MetLife owns and extends the rules
  • A load audit framework on Matillion surfacing source-versus-target counts at every layer
  • An organisation-wide data dictionary and PII classification framework

Outcome

99.9%

Data integrity and auditability. MetLife owns and extends the rules; every layer reconciled. Manual effort significantly reduced.

The Smith Family COMPLY

ADDF — automated data disposal and de-identification

BUSINESS PROBLEM

Keeping data longer than necessary created regulatory exposure, and manual disposal across multiple platforms was slow, error-prone and hard to prove.

WHAT WE BUILT

  • Automated scheduled purging at the end of retention periods
  • Removal of personal identifiers from data kept for analysis
  • Power BI reporting on disposal and de-identification status

OUTCOME

Compliant by default, with audit-ready reporting. Qualitative outcome — no percentage claimed.

Stack: Azure Synapse · Azure SQL · Microsoft Fabric · Power BI

The Smith Family AI ADOPTION

Snowflake Cortex knowledge search

BUSINESS PROBLEM

Knowledge was spread across Zendesk knowledge-base articles and SharePoint files, so finding an answer meant searching several systems.

WHAT WE BUILT

  • Zendesk content loaded into ADLS and indexed in Cortex Search
  • SharePoint files brought in via Openflow, with no custom integration layer
  • The pipeline tuned end to end, from ingestion through to indexing

OUTCOME

AI-ready knowledge in one search, with nothing bespoke to maintain. Qualitative outcome — no percentage claimed.

Stack: Snowflake Cortex Search · Openflow · ADLS · Zendesk · SharePoint
